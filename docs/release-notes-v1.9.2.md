## What's new

**Get your own weeks back from the marketplace.** Weeks you've published now have **Add to my courses** too, not just **Take down**. Use it on another computer, or if you've deleted a week. The week you add is linked to what you published, so publishing it again updates the same marketplace week instead of making a second one.

**Download a whole course at once.** A marketplace course has **Download missing weeks** and **Download all weeks**, on its page and on its card. It asks which of your courses the weeks go into (your course with the same name or module code is picked for you), says what's coming, and adds them in one go.

- Only one version of each week is added: the one you already have, else yours, else the most complete.
- Weeks you already added are left out. A blank week of yours with the same number is filled instead of adding another.
- **Published by you** has the same buttons for everything you've published, which is the easy way to set up a new computer.

**The app remembers what you've added.** Marketplace weeks you already have show **In <your course>** (or **Updated since you added it** if the author has published a newer version), and adding one again asks first.

**Weeks go where they went before.** Each marketplace course remembers which of your courses its weeks went into, so adding more goes straight there, with **Somewhere else…** to pick another.

**Week order on a marketplace course.** Choose **Week 1 first** or **Latest week first**. Your choice is remembered.

## Download

If you have 1.8.3 or later on Windows, Studywise offers this update by itself: it downloads in the background and installs when you restart.

Otherwise, on Windows, download `Studywise-Courses-Setup.exe` and run it. Your courses, decks and progress stay.

The app isn't signed. On Windows, click More info, then Run anyway.
